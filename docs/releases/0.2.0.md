# Fonn 0.2.0

Fonn now works inside the agent you already use. Add its hook once and keep running `claude`, `codex`, Crush, OpenCode or a desktop app on top of them.

- Run `fonn hooks install` to add Fonn's output filter to Claude Code, Codex, Crush and OpenCode through their own user settings. Fonn shows a diff with likely secrets hidden and asks before writing. It keeps your other settings and hooks, saves your original once as `<file>.fonn-backup`, and only ever changes the exact entry it added. `fonn hooks` shows the status, `fonn hooks uninstall` removes the entry, and `fonn hooks unlock` clears a lock left by an earlier run. Codex still asks you to trust the hook in `/hooks`; Fonn never does that for you.
- The Homebrew hook uses the stable `/opt/homebrew/bin/fonn` link, so it keeps working after `brew upgrade`.
- Run `fonn ui` for a local web interface on `127.0.0.1` behind a private link. The Agents page installs, updates and removes hooks. Other pages edit global and project settings, write filter rules and try them on a test bench, approve project rules, manage profiles, and list every hooked session and launch with what was shortened and the full originals.
- Write your own filter rules: plain-text "remove lines containing" matches for commands with a given prefix. They never remove problem lines. Rules in a project's files apply only after you approve them with `fonn config approve-rules`.
- Save global and project settings with `fonn config`: profile, filter mode, filter level and subagents.
- Clean up saved originals with `fonn records clean --older-than <days>`, or from the Activity page in `fonn ui`. Nothing is deleted on its own.
- Choose from built-in profiles for every listed Codex model, and run open models through Codex with a profile `source`, such as Ollama or LM Studio.
- Run `fonn chat --model <model>` for a small coding agent for open models with the filter built in. Its first request is under 1,000 tokens. It asks before every command and file change, and before reading likely secrets or sending files to a remote server.
- Use the standalone filter with Crush, OpenCode and Ollama, with a guide for other agents.

Documentation: https://fonn.nord-forge.dev. Upgrade with `brew upgrade --cask nord-forge/fonn/fonn`, then run `fonn hooks install`. The desktop GUI is planned and is not included. Character reductions are not measured token or billing savings.
