# Fonn 0.1.0

Initial CLI release of Fonn, an independent local harness around Claude Code and the Claude Agent SDK.

- Run `fonn` to open interactive Claude with an Opus or Sonnet effort profile and collapsed tool details. Ctrl+O expands details; display collapsing does not reduce model context.
- Create and edit local model/effort profiles and choose a default with `fonn profiles`; resumed SDK tasks retain their saved profile.
- Use `fonn run` for bounded SDK tasks with structured results, explicit approvals, recoverable output artifacts and estimated usage accounting.
- Reduce recognized noisy shell output conservatively, or choose observe/off modes. Unknown formats and arbitrary MCP issue payloads remain unchanged.
- Install the CLI through the cask in this repository. The archive contains Fonn JavaScript and lockfiles; Homebrew Node installs runtime dependencies on the user's machine without lifecycle scripts.

The desktop GUI is planned and is not included. Install and authenticate ordinary Claude Code separately for interactive use. SDK task runs require an explicit API key and separate API billing. Estimated stop thresholds can be exceeded, and character reductions are not measured token or billing savings.
