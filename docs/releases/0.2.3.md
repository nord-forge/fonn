# Fonn 0.2.3

A calmer `fonn ui`, and a new look for Fonn.

- Fonn has a logo: one line settling inside a rounded frame. It is the icon of `fonn ui`, the docs site and the repository, and the files are in `brand/`.

- Projects are a grid of cards with **Open** and **Rules** buttons, and a search box at the top that narrows them as you type.
- A project's overview shows three things: its filter mode, filter level and filter rules, each with where it comes from. One line says how much Fonn saved there once it filtered something.
- Link buttons look like the other buttons, and long folders keep their `~` at the start.

On the docs site, the "How it works" visualiser picks its sample from a dropdown, so its controls fit on one row.

Upgrade with `brew upgrade --cask nord-forge/fonn/fonn`. Documentation: https://fonn.nord-forge.dev.
