# Fonn 0.2.2

`fonn ui` now puts hooks and filter rules first.

- Build a filter rule from real output. Paste what a command printed, click the lines the model does not need, and Fonn suggests a plain text for each one without its numbers or times. A live preview shows what goes, and marks lines about errors, failures or warnings that always stay.
- Projects have their own page, with search, instead of a list in the sidebar. A project you save settings or rules for stays listed before any agent works in it, and **Forget** takes it off the list without changing the project.
- The Rules page says its rules are global and links to each project's rules. Save rules and Add rule sit side by side.
- The overview and each project's overview lead with what the hook uses: hooks installed, filter rules, filter mode and level. Profile and subagents only apply when Fonn starts the agent, so they sit lower.
- Agent cards only show the actions that apply, with their buttons lined up, and disabled buttons no longer show a busy cursor.
- Paths in your home folder show as `~`, so screenshots do not carry your user name.

Upgrade with `brew upgrade --cask nord-forge/fonn/fonn`. Documentation: https://fonn.nord-forge.dev.
