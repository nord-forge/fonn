# Fonn 0.2.1

- The Codex hook now has a name. Codex lists it as "Fonn output filter" in `/hooks` instead of "Unnamed hook".
- `fonn hooks` reports a Codex hook installed by 0.2.0 as written by an older Fonn. Run `fonn hooks install --agent codex` to add the name. Codex then asks you to trust the hook again in `/hooks`, because the hook changed.
- The install guide shows the plan Fonn prints before it writes, and the Codex review screens.

Upgrade with `brew upgrade --cask nord-forge/fonn/fonn`. Documentation: https://fonn.nord-forge.dev.
