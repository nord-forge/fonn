## Quick start

The [install guide](/start/install/) covers Homebrew and a source checkout.

```sh
git clone https://github.com/nord-forge/fonn.git
cd fonn && npm ci --ignore-scripts && npm run build
node packages/cli/dist/cli/main.js hooks install --agent claude
node packages/cli/dist/cli/main.js ui
```
