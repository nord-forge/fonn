## Quick start

With Homebrew on macOS:

```sh
brew tap nord-forge/fonn https://github.com/nord-forge/fonn
brew install --cask nord-forge/fonn/fonn
fonn hooks install     # shows each change and asks before writing
```

Then keep using your agent as usual. Using Codex? Open it once and trust the Fonn hook in `/hooks`. The [install guide](/start/install/) covers each agent, a source checkout, and the filter on its own without installing Fonn.
